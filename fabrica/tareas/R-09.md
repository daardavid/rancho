# Listo para probar en vivo

## Objetivo
Que INC-001 se pueda correr como un solo proceso y que los flujos principales estén cubiertos de punta a punta.

## Qué hacer
- `npm run build` en la raíz construye la web y la API. En producción, el mismo proceso de Fastify sirve la API en `/api` y la web en `/` (un solo origen, para que la cookie sea de primera parte).
- `npm start -w @rancho/api` arranca en modo producción leyendo `DATABASE_URL`, `PORT` y el secreto de sesión del entorno; falla con un mensaje claro si falta alguno.
- Playwright con unos pocos flujos contra la app construida y una base de prueba: iniciar sesión; dar de alta un animal con todo en «No sé»; capturar una sesión de pesaje de 3 animales con un hueco; corregir un peso; ver la ganancia en crecimiento.
- `docs/development/correr-local.md`: cómo levantar todo en una laptop (migrar, sembrar el rancho, crear la cuenta del propietario, arrancar).
- Actualiza la sección "PR mapping" de `docs/product/increments/INC-001-ficha-y-pesaje.md` con los PR de R-01 a R-09.

## Terminado cuando
- Los flujos de Playwright pasan localmente con `npm run test:e2e`.
- `npm run lint`, `npm run typecheck` y `npm test` pasan.
- El README dice cómo construir y arrancar en modo producción.

## Fuera de alcance
Elegir hosting, respaldos y el primer uso real (son INC-002).
