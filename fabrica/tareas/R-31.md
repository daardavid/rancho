Que olvidar el usuario o la contraseña no obligue a empezar con una base nueva, y que los documentos del MVP digan lo que se construyó. Ver INC-005.

## Qué hacer
- `npm run local`: cuando ya hay cuenta, muestra el usuario («Ya hay una cuenta: usuario <x>»). Nunca la contraseña ni su hash.
- Comando nuevo `npm run contrasena` (raíz) que cambia la contraseña de una cuenta existente en la base local, pidiéndola sin mostrarla en la terminal (reusa `leerContrasena`). Funciona con el servidor detenido, sobre `.datos/pglite`. Si hay varias cuentas, pregunta cuál. Al cambiarla, cierra las sesiones abiertas de esa cuenta y quita el bloqueo por intentos fallidos.
- Se niega a correr con `NODE_ENV=production`, igual que `npm run local`.
- Documenta los dos en `docs/development/correr-local.md`, en una sección «Si olvidaste tu usuario o contraseña».
- Documentos:
  - `docs/product/mvp-framing.md`: el Mapa de decisiones usa la numeración real (INC-001 ficha y pesaje, INC-002 local, INC-003 rediseño, INC-004 nacimientos, salidas, lugar, sanidad e Inicio; alimento, dinero y verificación como «Later»).
