# Notas de sanidad

## Objetivo
Que una vacuna, un medicamento, un baño o un problema visto quede anotado para un animal o un grupo, en lugar de solo en la memoria. Ver `TGT-HEALTH-001` y "Health, inside Herd" en `docs/architecture/domain-boundaries.md`.

## Qué hacer
- `HealthEvent` en Herd: animal o grupo (lista de animales), tipo (`vacuna`, `medicamento`, `bano`, `problema`, `otro`), qué se hizo o se vio, fecha, producto si se sabe, foto opcional (evidencia de R-14), y si la nota dice que el animal fue visto. Se agrega o se corrige con historia; no toca identidad ni tenencia.
- Nada de calendario, dosis, retiro ni flujo de veterinario.
- Web con la guía visual: «Anotar sanidad» desde la ficha y desde el modo de selección del hato (grupo); en la ficha, sección «Sanidad» con las notas en orden.

## Terminado cuando
- Pruebas: nota a un grupo queda ligada a cada animal; corregir conserva la anterior; «visto» es explícito y por omisión es falso.
- `npm run lint`, `npm run typecheck`, `npm test` y `npm run test:e2e` pasan.

## Fuera de alcance
Inventario de medicinas, recordatorios.
