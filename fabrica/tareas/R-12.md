# Base local y arranque con un comando

## Objetivo
Que David corra la app completa en su laptop con `npm install` y `npm run local`, sin instalar PostgreSQL ni Docker, y la abra desde su celular en la misma WiFi. Ver `docs/product/increments/INC-002-todo-en-local.md`.

## Qué hacer
- Base local con el motor de PostgreSQL embebido (PGlite) que ya usan las pruebas, con persistencia en una carpeta local (por ejemplo `.datos/`), ignorada por git. Puedes usarlo dentro del proceso o expuesto con `@electric-sql/pglite-socket` como hace `e2e/aplicacion.ts`; elige y explica. Mismas migraciones, mismo código de aplicación: nada de SQL especial para el modo local.
- `npm run local`: crea la carpeta si falta, aplica migraciones, siembra el rancho si no existe (pide el nombre si no está en `.env`), crea la primera cuenta si no hay ninguna (pide usuario y contraseña sin mostrarla, reusando `cuenta:crear`), construye si hace falta y arranca. Genera `SESSION_SECRET` con `crypto` si falta y lo guarda en `.env`. Correrlo otra vez no repite nada ni pierde datos.
- Escucha en la red local y muestra en consola las direcciones para abrirla desde el celular.
- La cookie: en modo local es HTTP en la red de la casa, así que sin `Secure` el celular no guardaría la sesión. Hazlo explícito (por ejemplo `MODO=local`), que el arranque lo diga en consola y que en producción siga siendo `Secure` sin excepción.
- ADR-015 (propuesto) en `docs/architecture/adr/`: en modo local de un solo usuario la app corre sobre PostgreSQL embebido con persistencia; producción sigue siendo PostgreSQL administrado (ADR-007). Agrégalo al índice de `docs/architecture/README.md`.
- Actualiza `docs/development/correr-local.md` y el README con el camino de `npm run local`.

## Terminado cuando
- Hay pruebas del arranque local: datos que sobreviven a apagar y volver a arrancar, segunda corrida sin duplicar rancho ni cuenta, secreto generado una sola vez.
- Una prueba demuestra que en producción la cookie lleva `Secure`.
- `npm run lint`, `npm run typecheck`, `npm test` y `npm run test:e2e` pasan.
