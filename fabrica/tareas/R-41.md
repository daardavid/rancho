# Exportar a hoja de cálculo

## Objetivo
Que quien prefiera Excel pueda bajar el hato, los pesos y los eventos. Ver INC-007.

## Qué hacer
- Pantalla «Exportar» desde el menú ☰ con botones para bajar, cada uno un archivo:
  - Hato: activos y dados de baja, con identidad, aretes, categoría, sexo, tenencia, potrero esperado, última observación.
  - Pesos: cada peso con animal, fecha, kilos, calidad (medido / observado / declarado), sesión, si fue corregido.
  - Eventos: nacimientos con filiación y certezas, salidas, sanidad, destetes, diagnósticos de preñez, movimientos de potrero, bitácora (los que existan al momento).
- Formato **CSV en UTF-8 con BOM**, separado por comas, que Excel abre bien en español con acentos. Sin librerías nuevas. Si crees que hace falta `.xlsx` real, propónlo en tu nota con su peso y no lo agregues.
- Los kilos se exportan como el texto guardado (punto decimal), nunca recalculados con `number`. Las fechas como `AAAA-MM-DD`. Lo desconocido como celda vacía con una columna de nota cuando haga falta distinguir «No sé» de «no aplica».
- Solo con sesión iniciada y rol `owner`. El archivo no incluye ids de sesión, hashes ni datos de cuentas.
- Nombre del archivo con el nombre del rancho y la fecha.

## Terminado cuando
- Pruebas de API: cada exportación con datos sintéticos tiene las columnas y filas esperadas; acentos y comas dentro de una nota se escapan bien; sin sesión devuelve 401; con rol `support` según la regla de ADR-010.
- Prueba: los kilos del CSV son idénticos al texto guardado.
- `npm run lint`, `npm run typecheck`, `npm test` pasan.

## Fuera de alcance
Importar, exportar dinero o alimento (no existen), exportación programada.
