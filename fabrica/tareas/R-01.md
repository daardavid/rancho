# Esqueleto de la app

## Objetivo
Dejar la base del monolito (API), la app web y los contratos sobre la que se construye INC-001, sin lógica del rancho todavía.

## Qué hacer
- Workspaces nuevos en el `package.json` de la raíz (que ya usa `apps/*` y `packages/*`): `apps/api` (`@rancho/api`), `apps/web` (`@rancho/web`) y `packages/api-contracts` (`@rancho/api-contracts`). No toques `apps/domain-map`.
- TypeScript estricto (`strict: true`) en los tres. Node según `engines` de la raíz.
- `apps/api`: Fastify como única capa HTTP, con logs Pino e id de petición. Ruta `GET /api/health` que responde `{ "ok": true }` con su contrato Zod en `packages/api-contracts`. Estructura vacía de `src/shared-kernel`, `src/modules`, `src/application`, `src/read-models`, `src/infrastructure`, `src/http` como en `docs/architecture/repository-structure.md`.
- `src/shared-kernel`: tipos y validadores de `RanchId`, `AnimalId`, `CommandId`, `Version`, `RecordedBy`, `ReportedBy` (texto libre, no es usuario) y `SourceQuality` (`measured`, `observed`, `declared`).
- `src/shared-kernel/kilos.ts`: convierte entre el texto de un peso (por ejemplo `"351.5"`, máximo 3 decimales, mayor que 0) y gramos enteros, y de vuelta a texto (`"351.500"`). Rechaza notación científica, comas, negativos y más de 3 decimales. Nada de `parseFloat` para el valor autoritativo.
- Prueba obligatoria de fronteras de importación (ADR-012) en `apps/api`: recorre `src/` y falla si código fuera de un módulo importa `modules/*/domain`, `modules/*/persistence` o la `application` interna de otro módulo (solo se permite su `index.ts`), o si un archivo de `domain/` importa `fastify`, `drizzle-orm` o librerías de autenticación. Inclúyele pruebas con archivos de ejemplo que violen cada regla.
- `apps/web`: Vite + React + TanStack Query, en español, que llama `GET /api/health` con el proxy de desarrollo de Vite y muestra si la API responde. Layout limpio para celular; sin diseño elaborado.
- Linter: uno solo para todo, el mismo que ya usa `apps/domain-map` (oxlint).
- Scripts en la raíz: `lint`, `typecheck` y `test` que cubren `apps/api`, `apps/web` y `packages/api-contracts`; `dev:api`, `dev:web`. Conserva `dev:map`, `build:map` y `lint:map`.
- `.github/workflows/ci.yml`: además de lo que ya hace con el mapa, corre `npm run lint`, `npm run typecheck`, `npm test` y las pruebas de la fábrica (`python -m unittest discover -s fabrica -p "test_*.py"`).
- `README.md`: cómo instalar y correr API y web.

## Terminado cuando
- `npm run lint`, `npm run typecheck` y `npm test` pasan en la raíz.
- Hay pruebas de `kilos.ts`, incluido un caso que con `float` perdería exactitud y los rechazos.
- La prueba de fronteras falla con los ejemplos que violan cada regla y pasa con el código real.
- Hay una prueba de `GET /api/health` con la inyección de peticiones de Fastify.

## Fuera de alcance
Base de datos, autenticación, módulos del rancho y pantallas reales.
